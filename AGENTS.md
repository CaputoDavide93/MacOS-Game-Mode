# Agent instructions

Game Ready is a free macOS app (SwiftUI, macOS 15+, Apple silicon) that checks
a Mac, its Wi-Fi and its internet before cloud gaming and finds what causes lag.
It is private by design: nothing leaves the Mac except test traffic to the hosts
in `Endpoints.allHosts`.

## Build, test, lint

```bash
make check     # scripts/check.sh: core tests, strings, diagram, shell lint, Release build
make test      # core test suite only (cd Packages/GameReadyCore && swift test)
make strings   # regenerate App/Resources/Localizable.xcstrings from tools/strings/*.json
make diagram   # redraw docs/assets/architecture-*.svg
make build     # Release build and dist/Game-Ready.zip
```

Run `make check` before and after a change; anything green stays green. CI runs
the same gate (`.github/workflows/ci.yml`); `release.yml` builds releases.

## Layout

- `Packages/GameReadyCore/`: pure Swift rules, grading and parsing, no I/O, with
  tests in `Tests/GameReadyCoreTests/`. Put logic here.
- `App/Sources/`: the app. `Probes/` measure, `Model/` holds state, `GameMode/`
  applies and undoes changes, `UI/` displays. The app measures and shows; it
  does not decide.
- `App/Resources/Localizable.xcstrings`: generated; never edit by hand.
- `project.yml`: XcodeGen definition; the `.xcodeproj` is generated.
- `tools/`: `strings/<lang>.json` + `gen_strings.py`, `gen_diagram.py`,
  `gen-icon.sh`, `strip_png.py`, `brand/brand_kit.py`.
- `scripts/`: `build.sh`, `check.sh`. `docs/`: start at `docs/README.md`.

## Do not change

- Bundle id prefix `io.github.caputodavide93`, the product name, the guard
  script's flag path and sudoers contract in `GuardScript.swift`, and public URLs.
- `Endpoints.allHosts` is the complete list of hosts the app contacts;
  `EndpointGuardTests` fails on any other. Adding a host needs a privacy doc update.

## Conventions

- Strings: edit `tools/strings/en.json` and every other `tools/strings/<lang>.json`
  (same keys, same placeholders), then `make strings`.
- Public repository: no home-network details, names, addresses or measurements
  from a real household. Screenshots use the demo data from `AppModel.loadDemo()`.
- Conventional commits (`fix:`, `feat:`, `docs:`, `refactor:`, `ci:`, `chore:`)
  authored by the repo owner. No co-author trailers, session ids or
  "generated by" lines in commits, PRs, issues or comments.
- Docs must be true of the code; generated files (strings catalogue, diagrams)
  are never edited by hand. User-visible changes get a `CHANGELOG.md` entry.
- Never commit secrets, signing identities, keys, tokens, IP addresses, private
  hostnames or personal e-mail. `.env.example` documents the optional `SIGN_ID`
  for `scripts/build.sh`. The one public contact address is caputodav@gmail.com.
- No purchases, ads or analytics.
